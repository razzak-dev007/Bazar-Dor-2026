# 🛒 বাজার দর (BazarDor)

দৈনন্দিন নিত্যপ্রয়োজনীয় পণ্যের বাজার দর, দামের ওঠানামা এবং প্রধান বাজারসমূহের বিস্তারিত বিশ্লেষণ জানার একটি আধুনিক ওয়েব অ্যাপ্লিকেশন।

## 📖 প্রজেক্ট পরিচিতি (Short Description)
**বাজার দর** প্ল্যাটফর্মের মাধ্যমে সাধারণ ক্রেতা ও ব্যবসায়ীরা দৈনন্দিন চাল, ডাল, তেল, সবজি, মাছ, মাংস ইত্যাদির তাজা পাইকারি ও খুচরা বাজার দর এক ক্লিকেই দেখতে পারবেন। এতে বিভিন্ন বিভাগের প্রধান প্রধান বাজারের সর্বনিম্ন, সর্বোচ্চ এবং গড় দর সুন্দরভাবে তুলে ধরা হয়েছে।

## 🌟 প্রধান ৫টি ফিচার (Key Features)

### ১. লাইভ প্রাইস টিকার (Live Marquee Price Ticker)
ন্যাভবারের ঠিক নিচে একটি ইনফিনিট স্ক্রলিং লাইভ স্ট্রিপ প্রদর্শিত হয় যেখানে প্রতিটি পণ্যের নাম, আজকের দর এবং মূল্য বৃদ্ধির/হ্রাসের শতকরা হার (▲/▼ %) লাইভ দেখা যায়। কার্সর রাখলে টিকারটি পজ হয়।

### ২. হোম পেজে দাম বাড়া ও কমার শীর্ষ পণ্য (Risers & Fallers Analysis)
হোম পেজে শীর্ষ ৬টি মূল্য বৃদ্ধি পাওয়া পণ্য (“আজ দাম বেড়েছে ▲”) এবং শীর্ষ ৬টি মূল্য হ্রাস পাওয়া পণ্য (“আজ দাম কমেছে ▼”) আলাদা আলাদা সেকশনে বাংলায় কার্ড আকারে প্রদর্শিত হয়।

### ৩. ক্যাটাগরি পেজ ও সংখ্যাভিত্তিক সর্টিং (Category Filtering & Numeric Sort)
ন্যাভবার ও ক্যাটাগরি মেনু থেকে প্রতিটি ক্যাটাগরির (চাল, ডাল, তেল, সবজি, মাছ ইত্যাদি) পণ্য আলাদাভাবে দেখা যায়। এতে ড্রপডাউন সর্টিং ব্যবস্থা রয়েছে যা বাংলা সংখ্যার সঠিক নিউমেরিক মান যাচাই করে কম থেকে বেশি বা বেশি থেকে কম মূল্যে সাজাতে পারে।

### ৪. বাজারভিত্তিক সুরক্ষিত বিস্তারিত বিবরণী (Protected Product Details Page)
কোনো পণ্যের কার্ডে ক্লিক করলে সরাসরি তার ডিটেইল পেজে যাওয়া যায়। এটি একটি প্রোটেক্টেড রুট যা শুধুমাত্র লগইন করা ব্যবহারকারীরা দেখতে পারেন। এখানে জাতীয় সর্বনিম্ন, সর্বোচ্চ ও গড় দরের পাশাপাশি বিভিন্ন আঞ্চলিক বাজারের (কারওয়ান বাজার, গ্রীন মার্কেট, সদর বাজার ইত্যাদি) দর বিশ্লেষণ দেখা যায়।

### ৫. বেটার-অথ অথেনটিকেশন ও প্রোফাইল আপডেট (Better Auth & Profile Update)
ইমেইল/পাসওয়ার্ড ও সোশ্যাল বাটনের মাধ্যমে সাইন ইন এবং সাইন আপের পূর্ণাঙ্গ সুবিধা। ব্যবহারকারীর নিজস্ব প্রোফাইল পেজ রয়েছে যেখান থেকে Challenge C3 অনুযায়ী Better Auth-এর `authClient.updateUser()` ব্যবহার করে নাম বা তথ্য সরাসরি আপডেট করা যায়।

### বোনাস ফিচার: ফ্রেন্ডলি ৪০৪ পেজ ও স্কেলেটন লোডার (Skeleton Loaders & Custom 404)
ডাটা লোড হওয়ার সময়ে সুন্দর পালস স্কেলেটন এনিমেশন এবং কোনো ভুল বা অননুমোদিত লিংকে প্রবেশ করলে বন্ধুত্বপূর্ণ বাংলা ৪০৪ পেজ (“হোম পেজে ফিরে যান” বাটনসহ)।

## 💻 লোকাল কম্পিউটারে রান করার নিয়ম (How to Run Locally)

১. রিপোজিটরিটি ক্লোন করুন:
```bash
git clone https://github.com/razzak-dev007/Bazar-Dor-2026.git
cd Bazar-Dor-2026
```

২. প্যাকেজগুলো ইন্সটল করুন:
```bash
npm install
```

৩. `.env.example` ফাইলটি থেকে একটি `.env` ফাইল তৈরি করুন:
```env
BETTER_AUTH_SECRET=bazardor_assignment7_secret_key_123456789
BETTER_AUTH_URL=http://localhost:3000
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

৪. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
ব্রাউজারে [http://localhost:3000](http://localhost:3000) ওপেন করলেই প্রোজেক্টটি দেখতে পাবেন।

৫. প্রোডাকশন বিল্ড যাচাই করতে:
```bash
npm run build
```
